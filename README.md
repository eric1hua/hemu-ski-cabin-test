# Hemu Ski — enterable cabin test

Standalone demo build of the cabin test tool from hemu-ski's `tools/review/`
(Kenney CC0 modular assets, three.js, the game's own toon rendering):
a two-storey cabin with a basement you can walk into with no loading,
place furniture in, and sleep in the upstairs bed.

**Play: https://eric1hua.github.io/hemu-ski-cabin-test/**

WASD move · drag to look · wheel zoom · E sleep (at the bed) · B decorate mode.
The hemu-ski main repo is untouched; this repo holds only the built demo.
